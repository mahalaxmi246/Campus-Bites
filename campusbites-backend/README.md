## Local setup

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # then fill in your real DB_PASSWORD and JWT_SECRET_KEY
```

Make sure MySQL is running locally and a `campusbites` database exists:
```sql
CREATE DATABASE campusbites;
```

Run the API:
```bash
uvicorn app.main:app --reload
```

Visit `http://localhost:8000/docs` for the interactive Swagger UI (auto-generated by FastAPI — this is what satisfies NFR5, API contract consistency, for free).

## Project structure

```
app/
  core/
    config.py       # env-driven settings (pydantic-settings)
    database.py      # SQLAlchemy engine, session, Base, get_db dependency
  models/            # SQLAlchemy ORM models (Day 3-4)
  schemas/            # Pydantic request/response schemas (Day 5+)
  routers/            # FastAPI route handlers, grouped by resource
  services/            # business logic, kept separate from route handlers
  main.py              # app factory, middleware, root/health routes
```

Migrations (Alembic) are added Day 3-4 once the first models exist.
